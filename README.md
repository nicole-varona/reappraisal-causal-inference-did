## MY457 Reappraisal: Urban Political Structure and Inequality in Early Modern German Cities
## Author: Nicole Varona

# Overview

This repository contains the reappraisal of:

> Schaff, F., 2024. "Urban Political Structure and Inequality:
> Political Economy Lessons from Early Modern German Cities."
> *The Journal of Economic History*, 84(2), pp. 517–553.
> https://doi.org/10.1017/S0022050724000135

Completed as the summative assignment for MY457 (Causal Inference for
Observational and Experimental Studies) at the London School of Economics,
Winter Term 2026. The reappraisal examines the identification strategy,
reproduces the main results in R (the paper was originally estimated in
Stata), and contributes an original sensitivity analysis using
the Rambachan and Roth (2023) framework.

# Data

The replication data is available in the paper's openICPSR repository at:
https://doi.org/10.3886/E202444V1

The following files are required to render the document:

| File                                     | Required for |
|------------------------------------------|--------------|
| `City_panel_replication_JEH.dta`         | City-level analysis (Table 2) |
| `Noerdlingen_panel_replication_JEH.dta`  | Individual-level analysis (Tables 1, 3, 4, 5; Figures 3, 4, 5, 6) |

Both files should be placed in a `data/` folder at the root of the repository.
The data is not tracked by this repository (per course policy).

# Setup

Open this project by selecting "Open Folder..." in RStudio (or Positron) and
choosing the `summative-reappraisal-LSE-62628-2526/` directory (not the .qmd
file alone). This ensures `here::here()` resolves all paths from the
repository root, regardless of where you place the folder on your machine.
The repository includes a `.here` file in the root that anchors the working
directory.

# Reproduction

The reappraisal is written in R and rendered from a Quarto (.qmd) file.

To render `MY457_reappraisal_62628.qmd`:

1. Clone this repository
2. Download the data files from openICPSR (see Data section above) and
   place them in `data/` at the repository root
3. Run `replication.R` to generate the pre-computed `.rds` outputs in
   the `output/` folder. This re-estimates all DCDH specifications
   (Tables 3, 4, 5) and event-study figures (Figures 3, 4, 5, 6) with
   100-replication clustered bootstrap. Computation time is approximately
   20 hours on a 16 GB machine.
4. Open `MY457_reappraisal_62628.qmd` in RStudio and click "Render"
   (or run `quarto render` from the terminal)

Note: the `output/` folder is not tracked by this repository due to file
size. The `replication.R` script regenerates it from scratch.

# Notes on code structure

- The `replication.R` script handles all heavy estimations. Outputs are
  saved as `.rds` files in `output/` so subsequent renders of the `.qmd`
  load them rather than re-estimating.

- The `.qmd` document itself runs only fast estimations directly:
  Table 1 (univariate OLS), Table 2 (TWFE city panel), and the Rambachan-Roth
  sensitivity analysis (TWFE event-study + sensitivity bounds).

- Helper functions for plotting and table formatting are defined in
  a setup chunk at the top of the `.qmd`.

# Known computational limitations

The "+ Controls" panels of Figure 3 (Panels A.II, B.II, C.II) and the
equivalent panels of Figures 4–6 are not included in the rendered document.
Estimating these specifications requires more memory than a 16 GB machine
permits, owing to the 61-dimensional occupational control set combined with
100-replication clustered bootstrap. The estimation code is preserved in
`replication.R` for execution on higher-memory hardware. Substantive
conclusions are unaffected: the Baseline specifications — which the author
treats as headline results — are fully replicated.
